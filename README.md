# Задание 1. Файлы и каталоги

## Описание

Программа моделирует простую файловую систему, состоящую из файлов и
каталогов. Каталоги могут содержать файлы и вложенные каталоги.

## Основные классы

-   `FileSystemElement` --- абстрактный базовый класс, задающий общий
    интерфейс элементов файловой системы.
-   `File` --- файл с текстовым содержимым; размер определяется длиной
    содержимого.
-   `Directory` --- каталог, содержащий файлы и другие каталоги; размер
    равен сумме размеров вложенных элементов.
-   `FileSystem` --- класс для управления файловой системой и работы с
    элементами по пути.

## Возможности

-   Добавление файлов и каталогов.
-   Проверка повторяющихся имён в одном каталоге.
-   Получение размера элемента.
-   Поиск по пути.
-   Рекурсивный вывод дерева каталогов.
-   Управление памятью с помощью `std::unique_ptr`.

## Используемые средства

C++, ООП, наследование, виртуальные функции, полиморфизм,
`std::unique_ptr`, контейнеры стандартной библиотеки.
